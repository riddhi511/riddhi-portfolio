# Riddhi Soni - Portfolio

My personal portfolio site, built to showcase my projects, skills, and experience as a software engineer.

**Live site:** (https://riddhi-portfolio-beta.vercel.app/)

## About

This is a single-page portfolio featuring:

- **About** — quick intro and resume link
- **Education & Experience** — a timeline of my academic and professional background
- **Projects** — flagship builds including SnapClass, SipDB, and Eventify
- **Skills** — languages, frameworks, and tools I work with
- **Certificates** — credentials from Google Cloud, Anthropic, CodePath, and AWS
- **Contact** — ways to get in touch

## Tech Stack

- [Angular](https://angular.dev/) 21
- Custom CSS (no framework)
- Deployed on [Vercel](https://vercel.com/)

## Development

Clone the repo and install dependencies:

```bash
npm install
```

Start a local dev server:

```bash
ng serve
```

Then open `http://localhost:4200/` — the app reloads automatically as you edit source files.

## Building

```bash
ng build
```

Compiles the app for production and outputs build artifacts to `dist/riddhi-portfolio/`.

## Deployment

This site auto-deploys to Vercel on every push to `main`. Preview deployments are generated for pull requests and other branches.
